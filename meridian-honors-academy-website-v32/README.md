# Meridian Honors Academy Website v6

This version is a true multi-page website with one consistent navigation menu.

Pages:
- Home
- About
- Academics
- Student Life
- Library
- Families
- Admissions
- Contact

Major updates:
- Removed the “Our proposed home” section and its adjacent campus image.
- Changed typography to Barlow Condensed headings and Source Sans 3 body text to match the supplied school-site reference more closely.
- Added a split footer with school contact information and an embedded OpenStreetMap centered on the proposed Crown Heights location.
- Added book covers and descriptions to the Library page. Covers load from the Google Books public API with a styled fallback if a cover is unavailable.
- Preserved the homepage slideshow, image transitions, and swipeable photo carousel.
- Simplified the site to one menu and gave every menu item its own page.
- Adjusted the visual tone toward community, family partnership, student voice, and public-school warmth.
